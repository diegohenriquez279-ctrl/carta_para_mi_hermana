Abrí el proyecto con Vite, no con Live Server

Esta carta está hecha con React, así que necesita que Vite la compile. Live Server (o abrir el archivo a mano) solo muestra una página en blanco.

En la terminal, parado en la carpeta del proyecto:

npm run dev

Después abrí el link que te muestra la terminal (suele ser http://localhost:5173).
